# Credit Risk Modeling

Portfolio project demonstrating consumer credit default prediction: synthetic
applicant data, logistic regression and XGBoost models, threshold analysis for
lending decisions, and SHAP explainability.

> **Data note:** All data in this project is **synthetic**, generated by
> `src/generate_data.py`. No real borrower data, bureau data, or employer
> models are used.

## Problem

A lender must decide which applicants are likely to default. The model has to
rank risk well (ROC-AUC, PR-AUC), and the business has to pick an operating
threshold: a strict threshold declines good applicants, a loose one books bad
loans. Explainability matters because declined applicants deserve a reason.

## Approach

1. **Synthetic data generation** — 30,000 applicants with income, credit
   history length, debt-to-income ratio, employment length, loan amount and
   purpose, delinquencies, and credit utilization. Default is driven by
   interpretable risk signals plus noise (~10% base rate).
2. **Baselines** — Logistic regression (scaled features) vs XGBoost
   (class-weighted), same stratified split, same metrics.
3. **Threshold analysis** — Precision/recall at several operating points, so
   the precision-coverage trade-off is explicit instead of hidden behind a
   single 0.5 cut-off.
4. **Explainability** — SHAP values on the XGBoost model (optional; the
   script runs cleanly without SHAP installed).
